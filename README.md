# RAMA WATCHES - Marketing Website ⌚

Welcome to the **Rama Watches** marketing website! This project is a premium, interactive, single-page web application built to showcase high-tech smartwatches, highlighting their impact on students and professionals.

## 🚀 Features
- **Single-Page Scrolling:** Seamlessly navigate between Home, Showcase, Benefits, About, and Contact sections.
- **Glassmorphism UI:** Modern frosted-glass aesthetic combined with neon glowing accents for a premium feel.
- **Interactive Modals:** Detailed hardware and component breakdowns for each smartwatch model.
- **Micro-Animations:** Parallax mouse tracking, 3D card tilt effects on hover, and smooth scroll reveal animations using IntersectionObserver.
- **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop screens.

## 🛠️ Technology Stack
This project is built using native web technologies for maximum performance without the overhead of heavy frameworks:
- **HTML5:** Semantic structure and accessible layout.
- **CSS3:** Custom properties (variables), Grid/Flexbox layouts, `@keyframes` animations, and backdrop filters.
- **JavaScript (ES6):** DOM manipulation, event listeners, and 3D math logic for hover effects.

## 📖 Component Highlights
Based on our field research, the following smartwatch components and capabilities are highlighted across our product lineup:
- **Processors:** Atmega328 Microcontrollers, Bio-MEMS based chips.
- **Sensors:** Heart rate, Accelerometers, GPS, Fall Detection, and Temperature sensors.
- **Displays:** High-res OLED and Transflective LCDs.
- **Connectivity:** Bluetooth 4.0/5.0 and Wi-Fi.

## 👨‍💻 Local Setup
To run this project locally on your machine:
1. Clone the repository:
   ```bash
   git clone https://github.com/meghanand1028/WATCHES-Marketing-Website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WATCHES-Marketing-Website
   ```
3. Open `index.html` in your favorite browser, or use a local server like Live Server in VS Code, or python's http server:
   ```bash
   python -m http.server 3000
   ```
4. Visit `http://localhost:3000` in your browser.
